## [2026-10-22] PlanBench-XL: Evaluating Long-Horizon Planning of LLM Tool-Use Agents in Large-Scale Tool Ecosystems

- Link: https://arxiv.org/abs/2606.22388
- Code: https://github.com/JiayuJeff/PlanBench-XL
- Domain: LLM reasoning — agentic planning and tool use
- Source: arXiv (2026-06-21); EMNLP 2026 Main
- Recommended by: agent
- Priority: high
- Topic tags: reasoning, agent, planning, tool-use, benchmark, robustness
- Broader trend: reasoning evaluation is moving from short, fully observed puzzles toward long-horizon interaction in large, partially observed, failure-prone tool ecosystems

### Recommendation summary

PlanBench-XL is today's strongest read because it evaluates a form of reasoning that deployed agents actually need: finding and composing tools over long horizons when the full tool universe is not visible and some paths fail. The paper combines a controlled benchmark (327 retail tasks, 1,665 tools, at least five dependent tool calls), ten-model evaluation, path-preserving failure interventions, and trajectory-level diagnostics. Its most useful finding is that retrieval alone is not the core bottleneck: agents frequently retrieve relevant tools, then fail to select, verify, or return to them.

### Why this matters now

Agent evaluation is rapidly moving beyond small, static tool menus. PlanBench-XL gives the field a concrete way to separate retrieval, planning, execution, verification, and recovery failures; it also shows that simply granting more turns produces only small gains. EMNLP 2026 Main acceptance and released code are meaningful validation signals, while citation evidence is still immature because the paper is only four months old.

### Core idea

- Hide the full tool set behind iterative retrieval, forcing agents to discover intermediate subgoals and compose tool chains rather than choose from a small supplied menu.
- Inject explicit, silent, or semantically misleading tool failures while preserving at least one valid path, so recovery and replanning can be measured cleanly.
- Diagnose trajectories with path-aware metrics, revealing that correct tools are often already in context but are ignored because of poor selection, recency bias, or failure contamination.

### Broader trend

This belongs to the shift from “reasoning as answer accuracy” toward reasoning as robust control over an interactive process. The important research object is no longer just the final response or chain of thought, but whether an agent can maintain state, search bidirectionally, verify tool outputs, backtrack after drift, and recover under partial observability.

### What to read skeptically

The benchmark is confined to 327 synthetic retail tasks and uses a datatype-grounded retriever, which is cleaner than production tool discovery and may underrepresent natural-language ambiguity. Its blocker taxonomy is controlled and useful, but simulated tool failures may not capture correlated outages, changing schemas, authorization errors, or other real deployment failures. Treat the model rankings as benchmark-specific; the durable contribution is the failure decomposition, not a universal leaderboard.
