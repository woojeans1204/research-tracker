### Recommendation Summary
This is the reasoning paper I would read today because it stress-tests a popular assumption: more inference-time compute should reliably improve agentic reasoning. General AgentBench evaluates ten leading agents across search, coding, reasoning, and tool-use tasks in a unified environment, then shows that both sequential scaling and parallel scaling hit practical limits: context overload for long trajectories and weak self-selection for sampled trajectories. The paper matters less as a new algorithm and more as a durable evaluation warning for anyone building or trusting test-time-scaled agents.

### Why It Matters Now
- The field is moving from single-domain reasoning benchmarks toward general-purpose agents that must infer intent, choose tools, and recover across heterogeneous tasks.
- The paper gives a concrete framework for measuring whether test-time scaling still works once the agent sees a shared, noisy, multi-tool environment rather than a neatly scoped domain setup.
- Its negative result is useful: it suggests that better search alone is not enough unless the agent can manage accumulated context and reliably verify or select among candidate trajectories.

### Core Idea
- Build a unified benchmark where agents face search, coding, long-context reasoning, and tool-calling tasks through one shared interaction interface.
- Compare domain-specific evaluation against a general-agent setting, showing substantial performance drops when agents must operate without task-specific scaffolding.
- Analyze sequential and parallel test-time scaling, finding a context ceiling for longer interactions and a verification gap for best-of-N trajectory selection.

### What To Read Skeptically
- The benchmark is broad by design, so inspect whether each component task is deep enough to support strong claims about reasoning rather than general agent robustness.
- Some findings may depend on the exact unified tool interface, prompting policy, and trajectory-selection method; these are likely to matter a lot for replication.
- Treat the negative scaling result as a diagnosis of current agent scaffolds, not as proof that sequential or parallel scaling cannot work with stronger memory, compression, search, or verifiers.
